# Privacy and Data Policy

- **Live Code Privacy**: Active collaborative code never touches server disks or database tables.
- **P2P Transport**: Content exchanges directly between client browsers via WebRTC.
- **Fallback Relay**: In-memory relay buffers chunks in volatile memory only for transit.
- **Subscriber Saves**: 48-hour server saves are encrypted, strictly scoped, and auto-purged.
- **No Tracking**: Free guest sharing requires no registration, cookies, or trackers.
